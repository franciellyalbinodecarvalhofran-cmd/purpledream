## Antes de começar

## Criar ambiente virtual

```powershell
python -m venv venv
```

## Ativar ambiente virtual

```powershell
.\venv\Scripts\Activate.ps1
```

## Instalar Django

```powershell
pip install django
```

## Criar requirements.txt

```powershell
pip freeze > requirements.txt
```

## Rodar servidor

```powershell
python manage.py runserver
```
