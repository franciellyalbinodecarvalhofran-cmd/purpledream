Rdar o App 
Criar ambiente virtual
python -m venv venv
Ativar ambiente virtual
.\venv\Scripts\Activate.ps1
Instalar Django
pip install django
Criar requirements.txt
pip freeze > requirements.txt
Criar projeto Django
django-admin startproject config .
Rodar servidor
python manage.py runserver
